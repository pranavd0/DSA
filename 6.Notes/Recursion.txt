================================================================================
                                   RECURSION
================================================================================

1. Concept:
   Recursion means dividing a problem into smaller instances of the same problem.

2. Core Components of Recursion:
   1> Recursive Function / Relation: f(n)
   2> Base Case: Condition where recursion stops (prevents infinite recursion / StackOverflow).

3. How Recursion Executes:
   1> Top-Down Approach (Calling Phase):
      Moves downward from the initial problem call f(n) toward the base case.
   2> Bottom-Up Approach (Returning / Unwinding Phase):
      Once the base case is reached, returns back up and combines the solutions step-by-step.

   Example: Factorial Calculation
   Recursive Relation : f(n) = n * f(n - 1)
   Base Case          : f(0) = 1

   Call Stack Visualization for n = 5:

   f(5) = 5 * f(4)
          ⬇       ↑
          4 * f(3)
          ⬇       ↑
          3 * f(2)
          ⬇       ↑
          2 * f(1)
          ⬇       ↑
          1 * f(0)  ->  Base Case (returns 1)

4. Standard Steps to Solve a Recursive Problem:
   Step 1: Define the function signature & recursive relation f(n).
   Step 2: Define Base Case (stopping condition).
   Step 3: Work / calculation for the current step.
   Step 4: Recursive call: f(n - 1) (inner call).
   Step 5: Return result to the previous caller (if returning a value).

5. Most Important Concept: Order of Execution (Call vs. Work):

   A) Pre-Recursive (Work First, then Recursive Call):
      - Executes work while going DOWN the call stack (Top-to-Bottom).
      - Make the recursive call AFTER performing work at the current step.
      - Example: Printing numbers from n down to 1.

   B) Post-Recursive (Recursive Call First, then Work):
      - Executes work while coming BACK UP the call stack (Bottom-to-Up).
      - Call the inner function immediately after the base case so it reaches the base case first.
      - Perform the work as the call stack unwinds / returns.
      - Example: Printing numbers from 1 up to n, Factorial, Fibonacci.

6. Final Structure / Implementation Template:

   Pattern A: Execution First (Pre-Recursion / Top-to-Bottom)
   ----------------------------------------------------------
   1> Define function f(n)
   2> Define Base Case (stopping / return condition)
   3> Work at current step (e.g., System.out.println(n) or state update)
   4> Inner call: f(n - 1)
   5> Return (if function returns a value)

   Pattern B: Inner Call First (Post-Recursion / Bottom-to-Up)
   ----------------------------------------------------------
   1> Define function f(n)
   2> Define Base Case (base value return)
   3> Inner call: f(n - 1) (dives to base case first)
   4> Work at current step (e.g., n * f(n-1) or print on return)
   5> Return (pass computed value back to previous step)
